# Marketing Funnel & Conversion Performance Analysis

## Overview
This project analyzes marketing funnel performance and conversion metrics to understand how users progress from visitors to leads and finally to customers. The objective is to identify funnel drop-off points, evaluate marketing channel performance, and provide actionable recommendations to improve conversion rates and business growth.

## Objectives
- Clean and preprocess marketing funnel data.
- Analyze visitor-to-lead and lead-to-customer conversion rates.
- Identify funnel drop-off points.
- Compare campaign and channel performance.
- Build an interactive Power BI dashboard.
- Provide business recommendations to improve conversions.
